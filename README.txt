How to run
1. Keep index.html, style.css, script.js and the assets folder together.
2. Double-click index.html, or open this folder in Visual Studio Code and use Live Server.
3. An internet connection is needed for Google Fonts and the external Unsplash photographs used elsewhere in the template.

Before publishing
- Confirm all school descriptions, school photos, affiliation statements and admission information with the school.
- Update event archive entries when new events are added.
- Connect the enquiry form to a backend/CRM if enquiries need to be stored or routed to school staff.
- Add a privacy policy and any required school disclosures.
